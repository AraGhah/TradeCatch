# TC-016 — Notify users of important Gmail replies

Verified October 24, 2026. Imported replies and owner-only alert outbox records
are saved atomically. Email and SMS are opt-in; external alerts omit the sender,
subject and message content. Dispatch rechecks current membership and preferences.
SMS goes to the mailbox owner's verified personal number. Updated both settings
translations to describe this correctly and added an explicit destination check.

All 11 alert tests passed, including isolated PostgreSQL persistence, rollback,
deduplication, concurrent claims, opt-outs and removed-owner checks. Enabled the
PostgreSQL alert suite in CI so these checks cannot silently remain skipped.

Live Gmail consent, provider delivery and deployment remain release checks.
