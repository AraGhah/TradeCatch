# TC-022 — Protect one-time login links

Verified October 25, 2026. All 16 login-confirmation and Worker-preview checks
passed, including memory and isolated PostgreSQL, with no skips. GET and HEAD
previews do not consume a token. Authentication requires explicit form POST,
matching confirmation nonce/cookie and permitted request origin. Expiry, replay,
French confirmation and racing POSTs are covered.

The Worker preview does not initialize token storage. JavaScript is unnecessary
for confirmation. No implementation change was needed. These checks establish
application behavior, not the current production deployment revision (TC-023).
