# TC-018 — Secure Gmail webhooks

Verified October 24, 2026. The webhook authenticates before reading its body or
looking up mailboxes. It requires Google-signed RS256 identity tokens with the
configured audience and verified service-account email. URL credentials are
rejected. Production signing keys come from Google's fixed certificate endpoint.

Expanded authentication regression coverage for stale issued-at timestamps,
future not-before claims, missing identity claims, oversized tokens, unavailable
signing keys and symmetric-signature substitution. All three authentication tests
passed; each exercises multiple rejection cases. Existing route tests also prove
unauthenticated requests cannot reach mailbox lookup.

No runtime change was necessary. Production Pub/Sub service-account permissions,
audience configuration and end-to-end push delivery remain release checks.
