# N-003 — Recover notification preferences loading

Added explicit localized loading, error and Retry states. Failed HTTP/network
requests and malformed preference payloads cannot produce a blank form or crash.
Aborted/stale organization loads do not overwrite current preferences.

Saving catches network errors, preserves edits and restores the save button.
Added English/French browser scenarios for delayed loading, failed/malformed
responses, retry and retained edits after failed saves. Full CI is required
before these changes merge.
