# TC-035 — Clarify Google Calendar availability

Reviewed October 25, 2026. Google Calendar is an explicitly allowlisted pilot;
a Growth plan or editable account flag alone cannot enable it. Simulated booking
is separate from real provider scheduling. Public/dashboard availability follows
the pilot gate; real Google calls are not established by mock-provider tests.

The capability matrix still has an obsolete blanket statement that provider
scheduling is unbuilt. That documentation correction is tracked separately as
N-008; TC-035 remains partial until the matrix is reconciled and release copy
is verified. Do not advertise Google/Outlook as generally available.
